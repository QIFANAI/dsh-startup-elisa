## 1. 适用环境

- Windows 11 + DeepSeek Harness Desktop `0.2.1-rc.5`（rc.3 兼容，api 未变）。

## 2. 安装 / 卸载 / 回滚

### 2.1 安装（一条命令）

```powershell
& powershell -NoProfile -ExecutionPolicy Bypass -File "<解压后的包根>\tools\install-elisa.ps1"
```

脚本流程：校验压缩包与 tgz SHA256 → 核对 包内全部文件哈希 → 备份 → 暂存 tgz 到 `~\.dsh\_packages\` → 已装则先 `dsh plugin remove` 再 `dsh plugin add`（pnpm 对同版本会判 `Already up to date`，不先卸载就修不好被改坏的文件）→ 6 项装后验收（版本 / 全部文件 / plugin list / bundles / 用户配置未改 / 其它插件未变）。

安装完成后：**完全退出 DSH（含托盘图标）→ 重新打开** 才生效。安装期间 DSH 可以保持运行（不必退出）；只有发生在 DSH 外的手动安装才建议先退出 DSH。

### 2.2 手动安装（等价）

```powershell
# 注意：不要用 $home（PowerShell 只读自动变量），用 $dshHome
$dshHome = Join-Path $env:USERPROFILE ".dsh"
$store   = Join-Path $dshHome "_packages"
New-Item -ItemType Directory -Force -Path $store | Out-Null
Copy-Item -LiteralPath "<解压后的包根>\dsh-startup-elisa-0.6.0.tgz" -Destination (Join-Path $store "dsh-startup-elisa-0.6.0.tgz") -Force
$env:DSH_HOME = $dshHome
# 已装过（含损坏需要修复）时先卸载；首次安装跳过（否则 pnpm 会报 CANNOT_REMOVE_MISSING_DEPS）
$installed = Join-Path $dshHome "profiles\desktop\node_modules\dsh-startup-elisa"
if (Test-Path -LiteralPath $installed) {
  & "<DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove dsh-startup-elisa
}
& "<DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add (Join-Path $store "dsh-startup-elisa-0.6.0.tgz")
```

（`dsh` 命令不在 PATH 时用上面完整路径；`$env:DSH_HOME` 一行保证装进当前用户的 DSH 目录。）

### 2.3 核验

```powershell
& powershell -NoProfile -ExecutionPolicy Bypass -File "<解压后的包根>\tools\verify-elisa.ps1"
```

输出 PASS/FAIL 明细：版本、全部文件哈希、profile bundles。任一项 FAIL 即安装不完整。
`DSH_HOME` 不是默认 `~\.dsh` 或 profile 不是 `desktop` 时，加上 `-DshHome "<...>" -Profile <...>`。

### 2.4 卸载 / 回滚

```powershell
$env:DSH_HOME = Join-Path $env:USERPROFILE ".dsh"
& "<DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove dsh-startup-elisa
```

修复被改坏的文件 = 重跑安装器（内部先 remove 再 add），**不要**在原文件上覆盖改写（pnpm 用硬链接共享 store，原位改写会污染共享内容）。

若 remove 失败：退出 DSH，把安装时生成的备份目录 `~\.dsh\_backups\elisa-install-<时间戳>\` 内的 `package.json`、`pnpm-lock.yaml`、`cordis.patch.yml` 拷回 `~\.dsh\profiles\desktop\`，并把该目录内的 `dsh-startup-elisa\` 拷到 **`~\.dsh\profiles\desktop\node_modules\dsh-startup-elisa\`**（是 `node_modules` 里面，不是 profile 根目录），再重开 DSH。**不要硬删备份目录。**

## 3. 启动时序（默认 80% 速度）

动画秒是契约值，墙钟 = 动画秒 ÷ 0.8：

| 墙钟（80%） | 动画秒 | 内容 |
|---|---|---|
| 0–1.44s | 0–1.15s | 黑幕开幕（DEEPSEEK HARNESS 字标 + 终端行 + 幕布拉开） |
| 1.44–9.00s | 1.15–7.20s | ELISA 冷启动 HUD（任意键 / 点击 / `Esc` /「跳过 SKIP」可跳过） |
| 9.00–9.95s | 7.20–8.05s | 交接转场（幕布合拢到绯红光缝 → 主界面「通电」显影，950ms） |
| 之后 | — | 主界面「毛玻璃」皮肤：呼吸动态主题背景（v0.6 呼吸 v2）+ 整窗背景模糊 + 输入框整圈流动光边框 |

- 速度 100% 总墙钟 7.2s；50% 约 14.4s；150% 约 4.8s。启动时长、交接、看门狗、宿主兜底计时按同一套速度公式换算，调慢不会误触看门狗。
- v0.6.0 新增/重做（用户点名两件事）：**背景呼吸 v2**（11 层，`breath/dim/rim` 统一 8.4s 同相叠加，亮相更亮、暗相更暗；暗帘只压暗不抬亮 → 对比度安全）；**输入框整圈流动光边框**（1.6px 主题环 + 8s/圈旋转 conic 光场 + 同角度 blur(7px) 外缘泛光 + 6.4s 呼吸相位锁定；删除 v0.5 的「小光点沿边框转」方案）。

## 4. 配置

配置文件：`~\.dsh\dsh-startup-elisa.json`（缺省自动补默认；安装脚本不会改动它）

```json
{
  "enabled": true,
  "mode": "session",
  "allowSkip": true,
  "reducedMotion": false,
  "sound": true,
  "volume": 65,
  "skin": "glass",
  "skinTheme": "aurora",
  "skinMotion": true,
  "glassTransparency": 50,
  "splashSpeed": 80
}
```

- `mode`：`session` 每个浏览器会话一次；`daily` 每天一次；`always` 每次打开都播放。
- `allowSkip`：关闭后隐藏跳过按钮，`Esc` 与「点击画面任意处跳过」同时禁用，只能自然结束。
- `reducedMotion`：不播放人物视频与粒子，静态终帧停留约 1.1 秒后走 300ms 简短交接；音轨只播 chime。**默认不跟随系统** `prefers-reduced-motion`，只有这里显式 `true` 才生效。
- `sound` / `volume`：启动音效与背景音乐开关；音量 0–100，默认 65，非法值回默认、超界钳制。
- `splashSpeed`：50–150（%），默认 **80**；100 = v0.4 原速。越小越舒缓（相位停留变长），音轨同步伸缩且**音高不变**；**保存后下次启动生效**。
- `skin`：`off` / `accent`（主题点缀）/ `full`（完整皮肤）/ `glass`（毛玻璃，默认）；**保存后立即生效**。
- `skinTheme`：`aurora`（绯红极光，默认）/ `deepsea`（深海蓝调）/ `violet`（紫夜霓虹）；仅 `glass` 档生效。
- `skinMotion`：动态背景（呼吸 + 漂移）开关，默认 `true`；关闭后静态。`reducedMotion=true` 时强制静态。
- `glassTransparency`：0–100，默认 **50**（= v0.4 标准观感）；越大越通透，越小越厚重；主界面、设置弹窗、账号菜单同步生效，**保存后立即生效**。
- `glass` 档固定深色语义：宿主「外观」切浅色时仍按深色玻璃渲染（文字/描边/状态色不跟随翻转），避免深色玻璃上深色文字不可读。

设置页：DSH 设置 →「ELISA 启动动画」。分组：播放（含**启动动画速度**滑块）/ 声音（含试听 4 秒）/ 外观皮肤（档位 + 主题背景 + 动态背景 + **玻璃通透度**滑块）/ 预览。启动动画相关设置「保存后下次启动生效」，外观与通透度「立即生效」。

## 5. 声音排错

- **完全没声音**：先确认配置 `sound=true` 且 `volume>0`；再确认系统未静音、DSH 未静音。
- **有画面没声音（Web 宿主）**：自动播放被拦时自动静音降级，并在**首次点击/按键**后从当前进度补播；点一下画面即可。Electron desktop 默认允许自动播放。
- **声音比画面晚**：若经手势补播会按动画已播秒数对齐，不会从头错位；明显不同步时检查系统负载。
- **调慢速度后声音变长/变低沉**：预期是变长但**音高不变**（`preservesPitch=true` 时间伸缩）；音高也变说明环境不支持 preservesPitch，属环境限制。
- **试听按钮提示「音频未生成」**：安装包缺少 `lib\assets\audio\boot.wav` —— 说明安装不完整，重跑 `verify-elisa.ps1` 并重装。

## 6. 皮肤排错

- **看不到皮肤差异**：设置页确认档位为「毛玻璃」（默认）；`off` 完全恢复宿主原样、`accent` 只换配色、`full` 为 v0.3 完整皮肤。
- **想临时还原原版**：设置页切「关闭」保存即可立即还原，无需重启；或配置 `skin` 改 `off`。
- **玻璃太厚/太透**：调「玻璃通透度」滑块（50 = 标准；越大越透）；设置弹窗、账号菜单与主界面同步变化。
- **对比度/阅读不适**：降低通透度、切「主题点缀」或「关闭」；毛玻璃只改配色、背景与装饰，不改字号、行高、布局与主要字体栈；也可关闭「动态背景」或选更冷色主题。
- **背景不呼吸/不流动**：检查「动态背景」开关；「减弱动态」开启时强制静态；页面切到后台会自动暂停（省电），切回前台恢复；低配（≤4 线程）或无 `backdrop-filter` 环境自动静态，属预期行为。
- **输入框边框没有流光**：确认皮肤档位为「毛玻璃」且未开启「减弱动态」；静态降级下仍保留一圈固定细光边。
- **毛玻璃变「实心」**：远程桌面 / 无 GPU / 浏览器不支持 `backdrop-filter` 时自动降级为高不透明度磨砂（保可读性），属预期行为。
- **皮肤没加载**：客户端只在 console warn `[dsh-startup-elisa] 皮肤样式加载失败`，不阻塞宿主；先跑 `verify-elisa.ps1` 确认 全部文件完整。
- **玻璃背景层残留在关闭后**：切 `off`/`accent`/`full` 会移除 `#dsh-elisa-ambient` 与 `--elisa-glass-a`；仍存在则检查其他插件样式冲突。

## 7. 排错（启动动画）

- **黑屏超过兜底时间**：宿主 `BOOTSTRAP_JS` 兜底强制放行（`__DSH_ELISA_FAILED__=true`）；默认 80% 时兜底约 17s，50% 时约 22.6s（按速度公式换算）；看 DSH 日志里 `[dsh-startup-elisa]` 的 warn。
- **交接处突然变黑/闪退感**：交接流程为「幕布合拢 → 光缝 → UI 通电」；默认 80% 约 950ms（100% 时 850ms）。若仍硬切：确认 `lib\splash.css` 的 `.elisa-handoff` / `.elisa-enter` 未被覆盖，且没有第二个启动插件同时注入。
- **视频缺失/解码失败**：离线预览页自动改静帧继续时间轴；宿主侧 iframe 异常时看门狗放行，不会卡死。视频在动画 6.0s 处冻结最后一帧（慢速下墙钟更晚），属设计行为。
- **播放两个启动动画**：同一 profile 还有 nostromo/yomi/screen；先卸载其他启动插件。
- **iframe 不显示**：确认 `/dsh-elisa/preview/index.html`、`/dsh-elisa/lib/assets/hero-loop.mp4`（支持 Range）、`/dsh-elisa/lib/audio.js`、`/dsh-elisa/skin.css` 均 200。
- **HUD 字段是 `—` 或短暂 `SYNCING`**：对应宿主 facts 未提供；启动层 3 秒内轮询配置，取不到保持 `—`，不影响播放。
- **desktop welcome: Web authentication failed**：与插件无关，是 Electron 默认会话 cookie 陈旧。完全退出 DSH，备份并移除 `%APPDATA%\@deepseek-ai\dsh-desktop\Network\Cookies` 与 `Cookies-journal`，再启动。

## 9. 已知限制（接受为已知风险发布）

1. **性能**：v0.6 输入框流光使软光栅 TaskDuration 相对 v0.5 **+173%**（FPS 未降）；GPU 合成口径实测 FPS 86–87、p95 帧间隔 14ms、无持续掉帧。**Electron 实机流畅度/功耗待用户重启后亲眼确认**。不可接受时的回退：设置里关「动态背景」/ 切 `full` 档 / 等后续小版本降旋转刷新率。
2. **背景可感知绝对值**：B1/B4 两项未达 plan 阈值（相对 v0.5 提升 4.4×/5.5×，峰谷比与固定点 ratio 已 PASS，设计评审判 PASS）。
3. 高 DPI/4K（1.6px 环、blur(7px)、呼吸幅度）未单独截图核对；`--noblur` / 低配 / 远程桌面降级路径仅逻辑与类名断言；24h 连续动画功耗未观测。
4. 60fps 逐帧平滑度：conic 角速度在 860×120 上非均匀（长边 165°/短边 15°），靠宽主弧掩盖；以 QA 60fps 成片与 design-review 判定为准。
5. 用户真实长对话/富文本/Web 预览的对比度以 QA 夹具会话为准；音频主观听感、`mode=daily` 跨天行为、看门狗故障注入未在本版重测。

## 10. 硬约束

- 同一 profile 只能启用一个启动插件。
- 第三方人物素材禁止上传或公开分发；音频为程序化合成、无外部版权素材。
- `desktop` 由 Electron 独占：在 DSH 之外手动装/卸时建议完全退出 DSH；在 DSH 对话内由代理安装无需退出，**重启 DSH 后生效**。
- 不用同一版本号覆盖已安装的 tgz；发版必须升版本号。
- 玻璃档固定深色语义；`backdrop-filter` 元素数 ≤3；v0.6 背景呼吸前提：`.ea-dim` 只压暗不抬亮。
- composer 光边框不得回退为「小光点/短光段」方案（用户点名廉价）；不得新增 `backdrop-filter`、不得改卡片布局。
