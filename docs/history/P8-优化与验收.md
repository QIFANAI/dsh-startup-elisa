# P8 · v0.6.0 优化与验收（代号 FLOW：背景呼吸 v2 + 输入框整圈流动光边框）


> **仓库说明**：本文是开发期记录的公开镜像，已脱敏本机路径与用户名。文中 `_pN/`、`_p8/`、`_build/`、`_shots-*`、`releases/_superseded/` 等为维护者本机目录，未随公开仓库分发；设计规格、评审与 QA 报告已单独放入 `docs/`。


- 产物：`releases\dsh-startup-elisa-0.6.0.tgz`
- 目标宿主：DeepSeek Harness `0.2.1-rc.5`（Win11 / Electron desktop + web）
- 用户诉求（原话，2026-11-02 02:32，附 9.0s 实机录屏）：
  1. 「背景还是没有呼吸的动态效果」；
  2. 「聊天框边框也不是呼吸动态效果」；
  3. 「流光效果是边框本身的动态环绕，不是找一个光点在那里转圈，看起来很廉价」；
  4. 「别的问题不大」。
- 用户实机口径：`skin=glass` / `skinTheme=aurora` / `skinMotion=true` / **`glassTransparency=100`（最通透档）** / `splashSpeed=50`；窗口 ≈1536×864 CSS、DPR1.25。
- 基线：`dsh-startup-elisa@0.5.0`（`P7-优化与验收.md`）
- 设计规格（唯一权威源）：`_p8\design-spec-v6.md`
- 外部参考与独立评审：`_p8\design\reference-research.md`、`_p8\design\review-v1.md`、`review-v2.md`

## 结论

v0.5 的两处被点名缺陷全部重做，其余能力不破坏：

1. **composer 边框从「静态环 + offset-path 小光点」整体替换为整圈流动光场**：`::before` 1.6px 主题环叠加 8s/圈旋转的 conic 光场（暖白前缘 + 主/副弧 + 完整底环），`::after` 同角度、同周期的 blur(7px) 外缘泛光（完全在卡外），两者 6.4s 呼吸相位锁定；删除 `offset-path`/`steps(48)` 小光段与相关回退分支。观感为「光沿整圈边框流动」，任何时刻边框都是完整可读的光边。
2. **背景呼吸重做为可感知**：新增 `.ea-dim` 暗帘呼吸层（只压暗不抬亮）与 `.ea-rim` 边缘呼吸光，`.ea-breath` 振幅加大、极光斑 glow 谷值下压、漂移加速；`breath/dim/rim` 统一 8.4s 单频同相叠加（亮相更亮、暗相更暗）。实测背景可见区亮度 range 6.0–9.5/255、右缘峰谷比 2.05（v0.5 全图帧差仅 1.8/255）。
3. **不破坏**：`off/accent/full` 三档、三主题、通透度/速度滑块、启动动画/音轨、静态/暂停/降级链全部保留；`npm test` **497/497** 全绿。

## 一、实现

### 1. composer 整圈流动光边框（`lib/skin.css` §4.8）

| 层 | 实现 | 参数 |
|---|---|---|
| `::before` 主题环 | `inset:0; padding:1.6px; border-radius:inherit` + conic 渐变 + `mask-composite:exclude` 抠环 | 底环 alpha 0.17–0.26；主弧 50°–112°（暖白前缘 `rgba(255,242,236,.72)`@66°）；副弧 196° 青 0.38；旋转 `@property --ea-flow-angle` 8s linear |
| `::after` 泛光 | `inset:-4px; padding:4px; border-radius:24px`（光带全在卡外）+ 同 conic + `filter:blur(7px)` | alpha ≈ 环 +0.06；opacity 0.18→0.55（6.4s）；与环同角度/同 8s |
| 呼吸 | 环 opacity 0.58→1（6.4s alternate）；泛光同步 | 与 8s 旋转互质（合成 32s） |
| 聚焦 | `:focus-within` 静态提亮（环 brightness 1.15 / 泛光 blur(7px) brightness(1.2)） | 不新增动画 |
| 降级 | `--static` 动画 none（静态完整光边 + 弱泛光）；`--paused` 暂停；无 `mask-composite` → 1px 实色描边；无 `@property` → 静态 conic | 兜底 `var(--ea-flow-angle, 0deg)` |

- 旧实现（v0.5）的 `offset-path: rect(...)`、`steps(48)`、`--ea-border-angle`、`ea-composer-orbit/flow` 关键帧与回退分支**已整体删除**；伪元素显式 reset `offset-path/width/height`，避免旧声明残留造成悬浮伪影（r2 修复项）。

### 2. 背景呼吸 v2（`lib/skin.css` §4.3 + `lib/client.js` ambientMarkup）

- 子层由 9 个增至 **11 个**：`base → b1..b4 → sheen → breath → grain → vignette → dim → rim`。
- 参数：`breath` 8.4s 单频（scale 0.92→1.10、位移 ±1.5%、opacity 0.10→0.44）；`dim` 8.4s 同相（opacity 0.76↔0.10，中心 alpha 0.10/边缘 0.50）；`rim` 8.4s 同相（0.10↔0.38）；blob glow 0.45–0.55→1（7.2/8.4/6.8/9.6s 错相）；漂移 22/26/24/30s、位移 10–16vmax。
- 对比度安全策略：`dim` 只降低背景亮度（峰值时中心 −10%、边缘 −50%），呼吸光提亮峰值不超过 v0.5 全层峰值；`header` 0.40 不透明下限沿用。

### 二.2 独立 QA 结论与性能裁决（qa-eng · `_p8/verify/qa-report-v6.md`）

**独立 QA 矩阵 30 项：PASS 23 / PARTIAL 2 / FAIL 3 / NOT_VERIFIED 1**；独立复跑 `npm test` 497/497、对比度 18 帧/1208 矩形 fail=0、`off/accent/full` 与 v0.5 **逐像素 0.0000（maxDiff 0）**、真宿主功能/降级/零位移/backdrop 全过、console 0 error。

用户点名的两件事产生可量化改善（QA 独立口径，v0.5 → v0.6）：
- **背景呼吸**：3s 帧平均差 0.665→**2.945/255（4.4×）**；亮度峰谷比 1.110→**1.393**；固定采样点整周期 ratio≥1.35 占比 5.0%→**71.4%**；1/4 周期块差 p90 0.542→**2.962（5.5×）**。
- **composer 边框**：环带 luma p50 峰谷比 1.087–1.149→**1.87–2.22（判据 ≥1.8 PASS）**；泛光呼吸比 1.19→**1.90**；整圈旋转 5.38s（小光点 offset-path）→**7.86–8.00s** 且方向单调一致性 1.000；1s 变化覆盖角 29–30°→**76–94°（2.6–3.1×）**；`offset-path: none` 实锤删除光点。

**FAIL 项判定（不阻塞发布，如实记录）**：
1. **B1/B4：背景可感知的绝对阈值未达 plan（2.95<6、p90 2.96<6）**——但相对 v0.5 提升 4.4×/5.5×，峰谷比与固定点 ratio 已 PASS，design-review 独立判 PASS；差异部分来自采样口径（QA 6fps vs Lead 0.94s 节拍，Lead 自测块 p90 4.53）。**结论：量级提升确认，绝对阈值口径偏严，不在本版追平。**
2. **P2：TaskDuration 软光栅 +173%（g100 1.1195s vs v0.5 0.4100s；g50 +185%），FPS 未降（144.2 vs 144.4）**。Lead 归因 A/B（`_p8/lead/perf-ab.json`，逐项关动画）：整体 1.122s → 关 composer 两伪元素动画 0.433s（−61%）→ 全静态 0.142s（−87%）；主因是 **`@property --ea-flow-angle` 角度动画使两个 composer 伪元素每帧重算样式/重绘**（RecalcStyleDuration 占 TaskDuration 约 45%），与 blur 无关（去掉 blur 反而 1.136s）。
   **Lead 补充实测（GPU 合成口径，headful Edge / AMD Radeon D3D11，隔离宿主 0.6.0）**：FPS **86–87**、帧间隔 p95 **14ms**、最大间隔 **14.5ms（无持续掉帧）**、TaskDuration **0.62–0.71s/3s**（约为软件光栅 144fps 口径的 58%，且按用户 60Hz 折算约 15% 主线程占用）。→ **裁决：接受为已知风险发布**（与 v0.5 TaskDuration FAIL 同级），需用户在 Electron 实机确认流畅度/功耗；若不可接受，回退手段：①设置页关闭「动态背景」；②切 `full`/`accent` 档；③后续小版本按 60Hz 优化（降低旋转刷新率/改用合成层方案）。

## 三、尚未验证的假设（禁止对这些项标 ✅）

1. **desktop（Electron `dsh-app://`）实机观感**：本轮以隔离 `dsh web` + Edge headless（1600×1020 / 1536×864 DPR1.25）等价验收；Electron GPU 合成下的观感与流畅度需用户重启亲眼确认。
2. **60fps 平滑度**：QA 已产出 `v6-composer-60fps.mp4`（源 79.7fps→60fps），Lead 抽帧 12 帧观察亮头沿边框连续移动、过角无闪烁；design-review 尚未对该 60fps 素材出具书面附注（其 review-v2 判定基于 8 帧序列+指标），本文件不以截图结论代替实机观感。
3. **性能**：软件光栅口径 TaskDuration v0.6 g100 **1.1195s vs v0.5 0.4100s（+173%，FAIL）**；GPU 合成口径（headful Edge / AMD Radeon D3D11）FPS 86–87、p95 帧间隔 14ms、无持续掉帧、任务占用约 15% 主线程（60Hz 折算）→ 需 Electron 实机确认流畅度与功耗（本文件不标 ✅）。
4. **高 DPI / 4K**：1.6px 环、blur(7px) 在 150%/200% 缩放下未单独截图（1536×864/DPR1.25 已覆盖一档）。
5. **`--noblur` / 无 GPU / 远程桌面**：降级路径仅逻辑与类名断言，未实测观感。
6. **`@property` / `mask-composite` 不支持环境**：静态 fallback 未在真实旧内核验证。
