## 交互口径

- 右上角 `跳过 SKIP`：真实鼠标点击后暂停视频，190ms 淡出到 P2 桌面占位页。
- `Esc`：与跳过按钮同一路径；自动播放被拦截时也会清掉“点击开始”遮罩。
- 6.4s 终帧：按任意键或点击画面进入桌面占位页，和画面提示一致。
- 不操作时：7.4s 自然播放结束后自动进入桌面占位页。
- `R`：桌面占位页重播启动序列。
- `?reduced=1`：不播视频，直接进入终帧并淡出；`prefers-reduced-motion` 同样生效。
- 调试参数：`?t=2.8` 冻结指定秒数；`?autoskip=2` 两秒后自动跳过。

交互测试结果：跳过点击、`Esc`、自动播放受阻后的 `Esc`、终帧 `Enter`、自然播放结束、`R` 重播、减弱动态全部通过；无浏览器异常。

## 运动连续性与接缝

并行版 4 个 worker 各自从分段起点启动渲染器，内部状态不同，导致 36 / 72 / 108 帧边界出现跳变。单进程版复用了同一个 `SceneRenderer`，从 0 到 143 连续步进。

| 分片边界 | 并行版帧差均值 | 单进程版帧差均值 | 结论 |
| --- | ---: | ---: | --- |
| 035→036 | 2.2223 | 1.4042 | 已回落 |
| 071→072 | 3.0159 | 2.3270 | 与相邻运动帧同级 |
| 107→108 | 2.2120 | 1.4992 | 已回落 |

单进程版全序列中位帧差 1.1223，最大 2.341（`075→076`）；`071→072` 为 2.327，和 `067→068` 的 2.3016、`075→076` 的 2.341 同级，属于人物连续运动，不再是孤立接缝。直接对比并行帧与单进程帧：0–35 帧逐像素完全一致，从 `f0036` 开始出现差异，定位与分片边界吻合。

渲染与编码：单进程 144 帧耗时 1,974.4 秒（约 32.9 分钟），无缺帧；调色 8.5 秒；H.264 High / yuv420p / CRF 20 / faststart / 无音轨。
