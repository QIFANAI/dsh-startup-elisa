# P6 · v0.4.0 优化与验收（代号 GLASS：毛玻璃 + 动态主题背景）


> **仓库说明**：本文是开发期记录的公开镜像，已脱敏本机路径与用户名。文中 `_pN/`、`_p8/`、`_build/`、`_shots-*`、`releases/_superseded/` 等为维护者本机目录，未随公开仓库分发；设计规格、评审与 QA 报告已单独放入 `docs/`。


- 产物：`releases\dsh-startup-elisa-0.4.0.tgz`
- 目标宿主：DeepSeek Harness `0.2.1-rc.5`（Win11 / Electron desktop + web）
- 用户诉求（原话）：「在此基础上做成毛玻璃效果的，带主题背景的UI界面，背景是动态的」
- 基线：`dsh-startup-elisa@0.3.0`（`P5-优化与验收.md`，三档皮肤 off/accent/full）
- 设计规格（唯一权威源）：`_p6\design-spec-v4.md`
- 对比基线截图：`_shots-v4\00-before-full-session-1600x1020.png`（v0.3 full）

## 结论

在 v0.3 皮肤体系上新增第 4 档 **glass（毛玻璃）** 并设为默认，用户诉求全部落地：

1. **毛玻璃效果**：`#root` 单层 `backdrop-filter: blur(26px) saturate(150%)` 整窗背景模糊 + 半透明玻璃令牌（侧栏/主区/输入卡/弹窗/菜单/Toast）+ 1px 高光描边与内顶高光，形成分层玻璃界面。
2. **带主题背景**：新增全屏动态背景层 `#dsh-elisa-ambient`（base 渐变 + 4 个极光斑 + 柔光扫过 + 噪点 + 暗角），三套主题 `aurora 绯红极光 / deepsea 深海蓝调 / violet 紫夜霓虹`。
3. **背景是动态的**：4 个极光斑 47/63/55/71s 漂移 + 38s 柔光扫过，只用 transform/opacity；`skinMotion` 开关、`reducedMotion` 强制静态、页面隐藏自动暂停、低配与不支持 backdrop-filter 自动降级。
4. **不破坏原有能力**：v0.3 的启动动画/交接/音轨/三档皮肤零改动可回退；`off/accent/full` 行为与 v0.3 一致（像素回归见验收表）。

## 一、实现

### 1. 玻璃档结构（自底向上）

| 层 | 元素 | 关键属性 |
|---|---|---|
| 画布 | `html.dsh-elisa-skin--glass` | 底色 `#050409`、`color-scheme: dark` |
| 动态背景 | `#dsh-elisa-ambient`（client.js 注入，fixed，`z-index:-1`，`pointer-events:none`，`contain:strict`） | `.ea-base` 主题渐变；`.ea-blob.ea-b1..b4` 极光斑；`.ea-sheen` 柔光；`.ea-grain` 噪点；`.ea-vignette` 暗角 |
| 毛玻璃 | `#root` | `backdrop-filter: blur(26px) saturate(150%) brightness(0.96)`（全屏唯一模糊层） |
| 玻璃表面 | 宿主 token 映射 | `--dsw-alias-bg-base` → `rgba(9,7,13,.22)`、`--dsw-specific-sidebar-fill` → `rgba(8,6,12,.42)`、`--dsw-specific-input-major` → `rgba(30,24,38,.52)`、`--dsw-alias-bg-layer-1/2/3`、`--dsw-alias-menu-surface-fill` 等 19 个令牌 |
| 细节 | 语义选择器 | 侧栏右缘 1px 冷光、输入卡玻璃描边/悬浮投影/聚焦绯红光环、模态面板额外 `blur(28px)` + 遮罩 `rgba(4,3,8,.55)` + `blur(8px)`、当前项绯红光条、header/tab 细线、顶/左 1px 装饰冷光 |

### 2. 主题与降级

- `html[data-elisa-theme]` 切换 `--ea-c1/c2/c3` 与 base 渐变：aurora（绯红/紫/青）、deepsea（青/靛/绯红）、violet（紫/绯红/青）。
- 降级链：`skinMotion=false` 或 `reducedMotion=true` → `--static` 静态背景；`document.hidden` → `--paused` 暂停动画；`CSS.supports('backdrop-filter')=false` 或 `navigator.hardwareConcurrency≤4` → `--static` + `--noblur`（玻璃令牌不透明度上调到 0.8+，观感为磨砂亚克力）。
- **玻璃固定深色语义**：宿主「外观」切浅色时，glass 档把 81 个随主题翻转的令牌强制回深色实测值，避免出现「深色玻璃 + 深色文字」（实测修复前 `--dsw-alias-label-primary=#08080b` 不可读 → 修复后 `#f2f0ea`）。

### 3. 配置与设置页

```json
{ "enabled": true, "mode": "session", "allowSkip": true, "reducedMotion": false,
  "sound": true, "volume": 65, "skin": "glass", "skinTheme": "aurora", "skinMotion": true }
```

- `skin` 增 `glass`（默认）；`skinTheme` ∈ aurora|deepsea|violet；`skinMotion` bool。非法值回默认/钳制。
- 设置页「外观皮肤」新增：皮肤档位四档（关闭/主题点缀/完整皮肤/毛玻璃）、主题背景（三选一，非 glass 档禁用）、动态背景开关（非 glass 或减弱动态时禁用）、说明文案；保存/恢复默认/读取配置后立即生效。
- 设置页显示版本 chip `v0.4.0`。

## 三、尚未验证的假设（禁止对这些项标 ✅）

1. **desktop（Electron `dsh-app://`）实机观感与重启播放**：以隔离 `dsh web` + Edge 等价验收；桌面端安装后需用户完全退出并重启 DSH 亲眼确认（尤其毛玻璃在 Electron GPU 下的观感）。
2. **高 DPI / 4K**：blur 半径按 CSS px，150%/200% 缩放下观感与 1px 细线未单独截图核对。
3. **软件合成 / 远程桌面**：已设计 `--noblur` 降级路径，但未在真实远程桌面/无 GPU 环境验证降级后的实际观感与性能。
4. **长时间功耗**：4 个 blob 的 24h 连续 GPU 占用未观测；已有页面隐藏暂停与静态开关。
5. **宿主升级**：CSS Modules 语义后缀（`_frame/_sidebarCol/_overlay/_panel/_mask/_card`）改版会静默降级为「token 玻璃」（仍有背景与半透明，高光细节消失）；token 主路径最稳。
6. **浅色主题完整性**：只抽验了 label/描边/状态 token 与截图可读性，未逐组件核对浅色宿主下所有特殊组件（如 Web 预览、富文本编辑器）。
7. **录屏/直播**：`backdrop-filter` 在录屏软件中可能被合成层丢弃，未验证。
