- 用户诉求（原话）：
  1. 「毛玻璃的透明度可调；」
  2. 「启动动画的速度可调，目前版本的速度属于比较快的，感觉比较仓促，需要提醒的是速度变慢相应的动效要符合观感逻辑；」
  3. 「背景貌似并不是动态的，没有呼吸感。」
  4. 「红框框出来的这些交互页面也是可调透明度的毛玻璃效果」（设置弹窗 / 左下账号菜单）
  5. 「对话框边框做成呼吸流光效果的」（聊天输入框 composer）

## 结论

v0.4 玻璃皮肤上完成五项能力，用户诉求全部落地：

1. **毛玻璃通透度可调**：新增 `glassTransparency`（0–100，默认 50 = v0.4 标准），`html` 行内 `--elisa-glass-a` 驱动 32 处玻璃 alpha（19 个宿主令牌 + 模态面板/遮罩 + 菜单 surface + noblur 降级）；主界面、设置弹窗、账号菜单等交互层共享同一变量，保存立即生效。
2. **启动动画速度可调**：新增 `splashSpeed`（50–150%，默认 **80%** = 9.0s，比 v0.4 慢 25%）；三层节奏模型（叙事 D=1/SPEED、冲击 I=1/√SPEED、氛围 1x），视频/音轨同速（音高不变），看门狗与交接同步换算；设置页滑块实时显示总时长。
3. **背景呼吸**：4 极光斑漂移 26/32/28/36s + 错相亮度呼吸 8.6/10.6/9.4/11.8s + 新增全屏呼吸光 `ea-breath` 9.2s（scale/opacity）；sheen 22s；实测 6.4s 两帧背景平均像素差 1.811/255（判据 ≥1.5），肉眼可辨。
4. **交互层玻璃**：设置弹窗（面板 + 遮罩 + 设置卡 + 导航）与左下账号菜单（surface/material + 菜单项 hover）随通透度同步变化（实测 alpha 单调，见证据）。
5. **输入框呼吸流光**：composer 输入卡两段式——静态 1px 主题渐变环（6.4s 呼吸）+ 110×2px 光段沿边框 offset-path 一圈（5.4s，steps(48) 分段位移），主题色跟随三主题；static/paused/`@supports` 降级；不新增 `backdrop-filter`、零布局位移。
6. **不破坏原有能力**：v0.4 的启动动画/交接/音轨/四档皮肤/三主题/固定深色语义/降级链全部保留；`off/accent/full` 与 v0.3/v0.4 像素级一致（meanAbsDiff 0.001）。

**独立验收结论（verifier · `_p7/verify/qa-report-v5.md`）**：17 项矩阵 **PASS 16 / FAIL 1**——功能全部通过（真宿主 199/199、速度 84/84、离线预览 79/79、对比度 537/537、回归像素级一致、滑块/清理全过）；唯一 FAIL 为**性能 TaskDuration**（软件光栅 +41.5%/+50.4%，FPS 达标），作为已知风险交付，需用户桌面实机确认；另有 8 条未验证假设（Electron 实机/高 DPI/noblur 低配/24h 功耗等）见「三」。

## 一、实现

### 1. 配置（新增两键）

```json
{ "enabled": true, "mode": "session", "allowSkip": true, "reducedMotion": false,
  "sound": true, "volume": 65, "skin": "glass", "skinTheme": "aurora", "skinMotion": true,
  "glassTransparency": 50, "splashSpeed": 80 }
```

| 键 | 范围 | 默认 | 映射 |
|---|---|---|---|
| `glassTransparency` | 0–100 整数 | 50 | `alphaMul = 1 + (50 - v) * 0.009` → 0→1.45 / 50→1 / 100→0.55；写入 `html` 行内 `--elisa-glass-a` |
| `splashSpeed` | 50–150 整数 | 80 | `SPEED = v/100`，`D = 1/SPEED`，`I = 1/√SPEED` |

- 100 档上限 0.55 由对比度预算决定（QA 首轮 0.35 映射在会话页原生绯红选中标签降至 3.50:1，判 FAIL；返工见 §二.1）。
- 非法值/缺键回默认；数值越界**钳制**（与 `volume` 同语义）；旧配置文件不迁移；`/dsh-elisa/config` 返回值、`defaults`、设置页脏检测、保存/恢复默认全部纳入新键。
- 宿主兜底计时 = `round(4000 + 7200/SPEED + 850·√(1/SPEED)) + 3000`（80% → 16950ms，50% → 22602ms），不再写死 14s。

### 2. 启动动画速度（`splashSpeed`）

| 层 | 缩放 | 实现 |
|---|---|---|
| 叙事层 | `D = 1/SPEED` | preview 主时钟 `t_anim = wall_elapsed × SPEED`；契约常量（T_OPEN 1.15 / TOTAL 7.2 …）不动 |
| 冲击层 | `I = 1/√SPEED` | `--elisa-sp` 缩放 11 条一次性 CSS 动作的 duration+delay（sweepGo / flareGo / bladeGo / flashGo / ringPulse / tbIn×5 / valIn 等） |
| 氛围层 | 1x | 粒子/羽毛/halo/pulse 等循环动画不缩放 |

- 交接：`HANDOFF_MS = round(850·I)`、`SKIP = round(480·I)`、reduced 300 / error 40 固定；`--elisa-k = clamp(ms/850, 0.02, 1.5)`（分母固定 850，视觉与清理同步拉伸；尾差 8–14ms 如实记录）。
- 看门狗：`clamp(round(4000 + 7200/SPEED + HANDOFF_MS), 8000, 30000)`（80% → 13950ms）。
- 媒体：`video.playbackRate = SPEED`（muted，6.0s 停最后一帧不循环）；boot 音轨 `playbackRate = SPEED` 且 `preservesPitch = true`（含 webkit/moz 前缀），chime 固定 1.0；`sync(t)` 语义不变。
- 设置页「播放」分组新增滑块（50–150%，步 5），提示实时显示当前总时长与「相位停留变长、冲击动作温和放慢、音轨同步伸缩且音高不变」；内嵌预览按草稿传 `&speed=`。

### 3. 毛玻璃通透度与交互层（`glassTransparency`）

- 玻璃令牌 alpha 全部改为 `rgba(R,G,B, calc(<base> × var(--elisa-glass-a, 1)))`，共 32 处：
  - 主界面：`bg-base / layer-1/2/3 / sidebar-fill / input-major / specific-menu / settings-card / button-floating / multi-select / button-elevated / hover-solid / module-platform / menu-surface / menu-group-header / toast / tooltip / onboarding-card`；
  - 交互层：模态面板 `[class*="_overlay"] [class*="_panel"]`、模态遮罩 `[class*="_mask"]`、菜单 material/`--dsw-menu-surface-fill`、菜单项 hover；
  - `--noblur` 降级的不透明度上调规则同样参与缩放。
- 通透度只改 alpha：`backdrop-filter` 半径（26px 整窗 / 28px 模态 / 40px 菜单）与 1px 高光描边保持不变。
- **header 局部兜底（返工新增）**：`#root header` 加 `background-color: rgba(7,5,10, max(0.40, 0.22*var(--elisa-glass-a,1)))`。宿主 header 原背景全透明，ambient 顶部绯红直透到选中 tab 文字背后；该下限不新增模糊、不改布局，确保 100 档会话页 tab 对比度达标，并让默认 50 档 header 最低对比度不低于 v0.4 的 95%。
- 设置页「外观皮肤」分组新增「玻璃通透度」滑块（0–100，步 5），glass 档启用、其余档禁用；提示文案说明 50=标准、越大越通透、设置弹窗与菜单同步、保存立即生效。

### 4. 背景呼吸

- 结构：`#dsh-elisa-ambient > .ea-base / .ea-blob×4 / .ea-sheen / .ea-breath / .ea-grain / .ea-vignette`（`client.js` 注入，切离 glass 时整体移除）。
- 动效参数：blob 漂移 26/32/28/36s（alternate）+ 错相 glow 呼吸 8.6/10.6/9.4/11.8s（0.80→1.0）；`ea-breath` 9.2s（scale 0.94→1.06、opacity 0.20→0.42，c1/c2/c3 混合）；sheen 22s；全部只用 transform/opacity。
- 亮度：b1 峰值 0.40→0.42（约 +5%）、b2 .40 / b3 .21 / b4 .16；`ea-breath` 呼吸 0.19→0.36；平均不高于 v0.4（呼吸下限低于原亮度）；返工后默认通透度下对比度达标（见验收）。
- 降级：`--static` 全部 `animation:none`；`--paused` 全部暂停；`prefers-reduced-motion` 未跟随（沿用插件约定，由 `reducedMotion` 显式控制）。

### 5. 输入框（composer）呼吸流光

- 钩子沿用 v0.4 输入卡玻璃规则；宿主卡片实测 `position:relative`，**不写 position / 不新增 DOM**。
- 两段式伪元素（避免每帧重绘整条渐变）：
  - `::before`：**静态** 1px conic 主题渐变环（`inset:0` + `padding:1px` + `mask-composite:exclude`），仅 `opacity` 6.4s 呼吸（0.78→1.0，合成属性）；
  - `::after`：110×2px 主题渐变光段，`offset-path: rect(0 100% 100% 0 round inherit)` + `offset-rotate:auto`，`offset-distance 0→100%` 5.4s 一圈（steps(48,end) 8.9 段/s 分段位移；逐帧 linear 实测主线程成本翻倍故弃用），`opacity` 6.4s 呼吸；
  - `:focus-within` 静态提亮；`pointer-events:none`。
- 降级：`--static` 两段停动画保留静态光边；`--paused` 暂停；`@supports not mask-composite` 退化 1px 实色描边；`@supports not offset-path` 退回 conic 角度旋转环（静态环隐藏避免双环）。
- 无新增 `backdrop-filter`；输入卡 rect 注入前后完全一致（零布局位移）。软件光栅 TaskDuration 增幅 +57.6% 超 §4 目标，作为已知风险记录（见「三、未验证」）。

## 三、尚未验证的假设（禁止对这些项标 ✅）

1. **desktop（Electron `dsh-app://`）实机观感与重启播放**：以隔离 `dsh web` + Edge headless 等价验收；桌面端需用户完全退出并重启 DSH 亲眼确认（尤其毛玻璃通透度、背景呼吸、输入框流光在 Electron GPU 下的观感）。
2. **性能预算（唯一 FAIL）**：输入框流光 + 呼吸层在 **headless Edge 软件光栅**下 TaskDuration 相对 v0.4 glass 中位 +41.5%（空页 0.578→0.817s）/ +50.4%（设置页 0.628→0.945s），超 §4 的 +25%；FPS 达标（99.2%/97.3%）。软件光栅 ≠ Electron GPU 合成，**该项不标 ✅**；需用户在桌面实机确认流畅度，若观感/功耗不可接受：①设置页关闭「动态背景」或切 `full`；②CSS 关闭流光（保留静态环，`_p7/g` 保留可回退片段）；③后续小版本按 `prefersCalm` 或流光线段数进一步降频。
3. **高 DPI / 4K**：1px 流光边、blur 半径与呼吸幅度未在 150%/200% 缩放下单独截图核对。
4. **软件合成 / 远程桌面**：`--noblur` 降级的流光/呼吸观感与性能未真实无 GPU 环境验证。
5. **长时间功耗**：新增呼吸层 + 流光伪元素的 24h 连续占用未观测（已有隐藏暂停与静态开关）。
6. **`@property` / `offset-path` 兼容**：宿主 Chromium 支持；`offset-path` 不可用时 `::after` 退回 conic 角度旋转环（`@property` 路径），两者均在 CSS 内置降级，但未在真实不支持环境验证。
7. **宿主升级**：CSS Modules 语义后缀（`_overlay/_panel/_mask/_card/_material`）改版会静默降级为「token 玻璃」；交互层通透度依赖 token 主路径。
8. **会话页对比度**：已用合成夹具会话（用户需求 + 助手多步 + Markdown 代码块/表格，111 文本矩形）覆盖并通过；但未覆盖用户真实长对话/富文本编辑器/Web 预览等特殊组件，不标 ✅。
9. **音频主管听感**：`preservesPitch` 已由属性实测，真实声卡下「音高不变」的主观听感未验证。
10. **`mode=daily` 跨天行为、12s/14s 故障注入路径**：沿用 v0.4 结论，本次未重测。
