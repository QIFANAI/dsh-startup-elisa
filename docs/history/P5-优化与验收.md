## 结论

用户对 v0.2.0 提出的四条再优化诉求已全部落地，并在隔离真宿主上完成验收：

1. **消除「闪退感」**：新增 850ms 设计化交接转场（HUD 退场 → 上下幕布合拢到 2px 绯红光缝 → 光缝展开 + 通电扫描 → 宿主 UI 显影 → 启动层移除），交接窗口内无纯黑硬切；实测 done→启动层移除 854.8ms（≤1000ms），最低亮度 5.45/255（设计黑场，无 <4/255 持续 >100ms 黑帧）。
2. **补 DSH 相关性**：新增 ACT 0 黑幕开幕（0–1.15s）：`DEEPSEEK HARNESS` 字标解码、终端启动行（`LOCAL NODE · COLD START` / `BUILD v0.3.0 · PROTOCOL ELISA`）、四角括号、电源点、绯红光缝、≤8% 点火白闪，上下幕布拉开揭示 ELISA。
3. **补音效与背景音乐**：程序化合成 7.8s 主声轨（19 个 cue：电源 thump、12 解码 tick、点火 ping、开幕 whoosh+impact、drone BGM、6 遥测 tick、锁定 clunk、握手心跳加速、剑光 shing、ONLINE 和弦、ready chime、退场下行）+ 1.35s chime（减弱动态）；设置页可开关/调音量/试听；自动播放被拦时静音降级、首次手势补播。
4. **消除 UI 割裂感 / DSH 客户端皮肤**：三档皮肤 `off / accent / full`（默认 full），覆盖 65 个宿主设计 token（暖黑纸白 + ELISA 绯红 + 圆角收紧）与 7 处克制的档案终端细节；保存后立即生效；不改布局/字号/字体栈/语义色，正文对比度抽检 457 个文本元素 0 个低于 4.5:1。

| --- | --- | --- |

## 二、实现

### 1. 总时间轴（wall clock，7.20s + 850ms 交接）

| 时间 | 相位 | 内容 |
| --- | --- | --- |
| 0.00–1.15 | `opening` | ACT 0 黑幕开幕（DSH 字标解码 / 终端行 / 括号 / 电源点 / 光缝 / 幕布拉开） |
| 1.15–2.25 | `boot` | HUD 分区浮入、电源横线、人物 3%→10% 显影、百叶窗揭幕 |
| 2.25–4.30 | `elisa` | 主体锁定框 2.70 出现 → 3.65 LOCKED → 4.35 收起；遥测 2.45–4.20 逐行锁定 |
| 4.30–5.35 | `handshake` | 进度加速、红色细线拉长、心跳脉冲 |
| 5.35–5.77 | `cut` | 剑光星芒 + 斜向光刃 + RGB 分裂 + 白闪 + 镜头 punch |
| 5.77–7.20 | `online` | HARNESS ONLINE；6.28 hint；6.62 HUD 退场；6.78–7.10 幕布合拢到光缝；7.20 done |
| 7.20–8.05 | 宿主 HANDOFF | 光缝→UI 通电显影；850ms 后移除启动层、解锁滚动 |

实测相位偏差 ≤0.06s；done 7.20s；`?t=` 定格、`?freezeAnim=`、`?reduced=1` 均保留。

### 2. ACT 0 黑幕开幕（preview/index.html）

- 全黑幕（`.op-cur` 上下两块）+ 中心 2px 绯红电源点（0–0.22）→ 字标解码（确定性伪随机，截图可复现）→ 四角括号逐边绘制 → 终端两行（真实插件版本）→ 0.98 点火白闪 ≤8% + 光缝 → 1.02–1.15 幕布拉开揭示 ELISA → 1.15–1.35 开幕层淡出隐藏。
- 纯 CSS/SVG/文字，无新增素材。

### 3. 交接转场 HANDOFF（lib/splash.js / lib/splash.css）

- iframe 内：6.62 HUD 分区退场（60ms 间隔）→ 6.78 上下纯黑幕布合拢 → 7.10 完全黑场 + 2px 绯红光缝呼吸 → 7.20 发送 `done`。
- 宿主：`root.elisa-handoff` + `html.elisa-enter` + `.elisa-seam` / `.elisa-wash` 装饰；0/120/240/260/850ms 分阶段（root 背景 380ms 变透明、iframe 420ms 淡出、UI 只动 opacity 0.55→1、通电扫描 380ms）；结束清理类名与装饰、解锁滚动。
- 实测：natural 854.8ms（三次 854.8/856.6/857.5）；skip 488.2ms（用户跳过→移除 766.4ms）；reduced 304.3ms；timeout/error 45.4ms；交接窗口最低亮度 5.45/255，无 <4/255 黑帧；红缝→通电过渡帧 ≥3 帧可辨。
- 看门狗 8s→12s，宿主 `BOOTSTRAP_JS` 兜底 12s→14s。

### 4. 音频（lib/audio.js + lib/assets/audio/）

- `boot.wav`：44.1kHz/16bit/stereo，7.800s，峰值 -1.2 dBFS，RMS -20.5 dBFS，开头 0.2s 静音、7.4s 后衰减到静音；19 个 cue 与时间轴对齐（数值自检 45/45）。
- `chime.wav`：44.1kHz/16bit/mono，1.350s，减弱动态分支。
- 引擎（389 行）：`init/start/sync/stop/state`，HTMLAudioElement；自动播放被拒 → `blocked` + 一次性手势补播（从当前动画秒数对齐）；404/解码失败只 warn 一次并静音继续；音量钳制；stop 淡出。
- 配置：`sound`（默认 true）、`volume`（0–100，默认 65）；`reducedMotion` 时只播 chime。
- 设置页「声音」分组：开关、音量滑杆、试听 4 秒（带 404 守卫）。

### 5. DSH 客户端皮肤（lib/skin.css + lib/client.js）

- 三档：`off`（零样式，宿主原版）/ `accent`（只换 token）/ `full`（默认，token + 7 处克制细节）。
- token：覆盖 65 个宿主 token（暖黑灰阶 27、品牌蓝→绯红阶 23、语义别名 9、圆角 6），并处理宿主把 token 声明在 `body[data-ds-dark-theme]` 与 body 硬编码底色的实际结构。
- full 细节：顶部/左侧 1px 绯红细线、当前会话/导航项 3px 渐变条 + 极淡绯红底、header/composer 1px 线、active tab 下划线、composer focus ring、caption 等宽、极淡扫描线/噪点纹理（不透明度 0.022）。
- 约束：不改字号/行高/字重/主字体栈；不挪布局；装饰层 `pointer-events:none`；语义色（错误/成功/警告）不动；正文对比度抽检 457 个文本元素，accent/full 全部 ≥4.5:1（最低正文 5.9:1，占位符 5.26:1）；off/full 同页平均绝对差 7.49/255（≈2.9%），最大局部均值差 5.4%（可辨识但不刺眼）。
- 加载：`apply(ctx)` 先读服务端注入 config 同步套用、再 fetch 校准；注入一次 `/dsh-elisa/skin.css`；与启动动画开关无关；保存/恢复默认后立即生效；失败只 warn 不阻塞宿主。

### 6. 设置页与配置

- 设置页新增「声音」「外观皮肤」分组；保存提示区分「外观已生效 / 启动动画下次生效」；版本 chip 真实 `v0.3.0`。
- 配置（`~\.dsh\dsh-startup-elisa.json`）：

```json
{ "enabled": true, "mode": "session", "allowSkip": true, "reducedMotion": false,
  "sound": true, "volume": 65, "skin": "full" }
```

- 旧配置缺键自动补默认；非法值回默认/钳制。
- 宿主新增路由：`/dsh-elisa/lib/audio.js`、`/dsh-elisa/skin.css`；assets MIME 增加 `audio/wav`。

## 四、尚未验证的假设（禁止对这些项标 ✅）

1. **desktop（Electron `dsh-app://`）实际重启播放**：本轮以隔离 `dsh web` 宿主 + Edge 等价验收；桌面端安装 0.3.0 后需用户完全退出并重启 DSH 亲眼确认。自动播放策略在 Electron 默认放行、audio.js 有手势补播兜底，但未在真实桌面实例上验证。
2. **高 DPI（150%/200%）与 4K**：未单独截图核对（沿用 v0.2 遗留项；皮肤 1px 细线/纹理在高 DPI 下观感待用户实机确认）。
3. **`mode=daily` 跨天行为**：未时间穿越验证；沿用 v0.2 的 UTC 日期边界（中国时区每天 08:00 切换），本版未改。
4. **宿主升级后的皮肤钩子稳定性**：full 档细节依赖 CSS Modules 语义后缀 / `role` / `aria` 钩子；宿主改类名时对应细节会静默降级（不影响功能与布局）。
5. **12s/14s 看门狗失败路径**：逻辑自测（timeout 45.4ms 释放）已验，未做宿主侧故障注入。
6. **主观听感**：音频以数值/频谱/包络自检为准（无外部版权素材）；人耳审美需用户实听确认，可调音量或关闭。
