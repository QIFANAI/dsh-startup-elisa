v0.1.5 的「可用但不耐看」问题已在 v0.2.0 从**布局、动效、交互、逻辑**四条线重做：舞台由固定 1920×1080 缩放改为全屏自适应；6 秒静帧级视频改为「HUD 叙事 + 光扫/粒子/锁定框/剑光切场」的编排；退场由黑场硬切改为 320ms 交叉淡化；交互补齐点击任意处 / 终帧自动退出 / 禁用跳过 / 减弱动态；facts 改为就绪轮询并逐项锁定。设置页新增内嵌预览。

## 二、优化内容

### 1. 布局：全屏自适应（去掉舞台缩放）

- 舞台 = 视口 100%，无 transform 缩放；安全边距 `clamp()`；字号随 `vmin` 钳制（10–14px 小字、42–112px 标题）。
- 视频/静帧 `object-fit:cover` + `object-position:64% 46%`，任意宽高比铺满；窄屏/矮屏自动降级隐藏次要 HUD。
- 五视口实测：1920×1080 / 1295×823 / 1280×800 / 2560×1080 / 3440×1440 全部无黑边、无滚动条、无重叠。

### 2. 视觉：精密档案终端

- 统一 token：底色 `#06060a`、纸白 `#f2f0ea`、红 `#e01b2f`；琥珀仅用于 LIVE 点；三个字号层级。
- HUD 重排：左上字标 → 左中自检遥测（6 行逐项锁定 + 步骤刻度 + PLUGINS/BUILD 脚注）→ 左下相位标题（kicker/大标题/中文副题/meta/红色进度细线）→ 右下 SYNC% + 24 格进度 + FRAME/T+；右上状态与跳过。
- 主视觉：百叶窗揭幕（mask 驱动）、档案切片闪切、主体锁定框（四角+准星+环形脉冲，2.45s 翻转 LOCKED）、光扫、羽毛/尘埃/余烬/星芒粒子、扫描线与暗角。
- 剑光切场：4.75s 剑光星芒 + 斜向光刃 + RGB 分裂 + 白闪 + 镜头推刺。

### 3. 动效与节奏（主时钟 = wall clock，6.10s）

| 时间 | 相位 | 关键动效 |
| --- | --- | --- |
| 0.00–1.35 | COLD BOOT | HUD 分区 120/220/320/420ms 依次浮入；电源横线；人物 3%→10% 显影 |
| 0.55–2.05 | 揭幕 | 百叶窗 mask 0→100%；档案切片两次闪切；第一次光扫（1.02s） |
| 1.35–3.60 | ELISA | 主体锁定框出现（1.40s）→ 锁定（2.45s）；遥测逐行锁定；相机缓推；粒子渐入 |
| 3.60–4.75 | HANDSHAKE | 进度加速；红色细线拉长；锁定框收起 |
| 4.75–5.17 | CUT | 剑光星芒 + 斜向光刃 + RGB 分裂 + 白闪 + 镜头 punch；标题切 HANDSHAKE OK |
| 5.15–6.10 | HARNESS ONLINE | 终帧标题、进入提示、自动进入退场 |

### 4. 交互

- 跳过：右上按钮（≥44×32 命中区）、`Esc`、**点击画面任意处**（加载 350ms 后生效）。
- 终帧：任意键 / 点击进入；5.15s 显示「按任意键进入 · PRESS ANY KEY」。
- 自动：6.10s 到终帧后 0.9s 自动进入宿主；不再出现「播完还要等」。
- `allowSkip=false`：按钮隐藏、Esc/点击禁用，仅自然结束。
- 跳过与退场：就绪/完成 postMessage 协议不变；宿主 320ms 交叉淡化，无黑场硬切。
- 自动播放受阻：显示「点击开始」遮罩；视频解码失败自动改静帧并继续时间轴。

### 5. 逻辑与宿主接入

- `lib/splash.js`：新增 ready/progress 消息；启动遮罩等首帧就绪才移除；看门狗 12s→8s（保留宿主侧 12s 兜底）；交叉淡化退场（`.elisa-done` → root 透明 + iframe 淡出 320ms → 移除）。
- facts：iframe 侧 `/dsh-elisa/config` 未就绪时 160ms×12 轮询；就绪后按锁定顺序填入，缺失显示 `—`；新增 `WORKSPACE`、`PLUGINS` 展示。
- 配置/API：键与语义不变（enabled/mode/allowSkip/reducedMotion）；`window.__DSH_ELISA_API__` 保持 replay/skip/finish/state/progress，新增 ready/facts。
- 调试接口：`?t=` 定格、`?freezeAnim=<ms>` 动画定格、`?probe=1` phase 时间戳、`?embed=1&preview=1` 面板内预览。

### 6. 设置页

- 重做面板：版本 chip、分组「播放」开关/播放时机三段/允许跳过/减弱动态、「预览」分组、保存/恢复默认/放弃修改、状态行、配置路径。
- 新增**内嵌预览**：全屏遮罩 + iframe 按当前草稿参数播放一次，`done`/`Esc`/关闭按钮/背景点击/超时五种关闭路径；不写配置、不写 sessionStorage。

- 冒烟：host 54 + splash 24 + client 15 = **93 项**。
- 离线交互验收 `scripts\qa-preview-v2.mjs`：**27 项**（含相位时间轴、全屏铺满、字号、切场定格、console 0 error）。
